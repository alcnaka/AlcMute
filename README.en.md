# AlcMute

[日本語](README.md) | **English**

**VRC Background Mute — toggle your VRChat microphone with a shortcut, even while another app is active.**

A Windows 10 / 11 tray app using VRChat's official OSC support.

## Download

**[Download the latest release](https://github.com/alcnaka/AlcMute/releases/latest)**

For most users, choose the Installer edition.

**A warning appears when downloading or starting AlcMute?** Follow the [steps for your warning](docs/user-guide.en.md#blocked-by-security-software), including how to keep the download in Edge and what to check when startup is blocked.

| | Installer | Portable |
| --- | --- | --- |
| Download | `AlcMute-…-Setup.exe` | `AlcMute-…-Portable.zip` |
| Getting started | Run Setup | Extract the ZIP and run `alcmute.exe` |
| Start at Windows sign-in | Supported | Not supported |
| Updates | Update from the app | Replace manually |

## Getting started

1. Enable **OSC** and **Toggle Voice** in VRChat.
2. Start AlcMute. The Installer edition is available in the Start menu.
3. Press **Ctrl + Alt + M** to toggle mute. You can change the keys in Settings.

Closing Settings leaves the app running in the tray. Choose Exit from the tray menu to quit.

Choose System, Japanese, or English under Language in Settings, then click Save.
