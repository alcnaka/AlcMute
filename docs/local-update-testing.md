# ローカル更新テスト

公開Releaseやインターネット接続を使わず、更新処理を検証します。
Rustの依存関係は事前に取得しておき、Inno Setup 6とWindows付属の.NET Framework C#コンパイラーを使用します。

```powershell
./scripts/test-update-local.ps1 -Iscc 'C:/Program Files (x86)/Inno Setup 6/ISCC.exe'
```

必要なら`-TargetRoot <既存のCargoビルド先>`を指定します。Cargoは`--offline --locked`で実行します。

テスト専用の0.0.1／0.0.2 EXEとInno Setupを生成し、ループバックHTTPサーバーを通して更新情報・チェックサム・インストーラーを取得します。本番と共通のダウンロード検証、親プロセス終了確認、バックアップ、インストール、バージョン確認、バックグラウンド再起動を実行します。

APIエラー、不正なAsset URL、破損したダウンロード、インストーラーの失敗も確認します。終了済み親プロセスのハンドルを保持し、以前の`os error 31`の条件を再現します。

実行ごとのGUIDでファイルとテスト用レジストリを分離します。通常のAlcMuteのプロセス・インストール先・設定・自動起動登録は変更しません。テスト用レジストリはスクリプトの終了時に削除し、ログと成果物は`results/local-update-tests/<GUID>/`に保持します。

成功すると同フォルダーに`report.json`が生成されます。失敗時はCargo出力と各ステージのインストーラーログを確認してください。

ローカル通信への差し替えはRustの`cfg(test)`限定で、配布EXEにHTTP接続や配信先変更の機能は追加しません。

## 検証範囲

これは更新処理の結合テストです。本番のAlcMute UI、更新ヘルパーの別プロセス起動、本番インストーラーの移行処理、GitHubへのHTTPS接続、OSC・ショートカットの実操作は別途確認が必要です。公開Release全体の動作保証を置き換えるものではありません。
