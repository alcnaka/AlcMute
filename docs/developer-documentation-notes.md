# ドキュメントから分離した開発者向け情報

利用者向け原稿には、操作に必要な情報だけを記載する。生成方式や検証状況は`CONTRIBUTING.md`と`scripts/docs/README.md`に記録し、Web・PDFには出力しない。

## 設定・移行の内部仕様

- 自動起動状態はWindows登録を正とし、settings.tomlに保存しない。Portable版はRunキーを変更しない。
- 旧`%LOCALAPPDATA%\VRChatMuteController`の設定を新保存先へ移行する。新保存先の設定を優先し、旧ファイルは保全する。
- 自動起動移行はInstaller版のインストール時に実施する。識別不能な登録は残してログに記録し、Windows側の無効状態も維持する。
- 初期値は保存を省略する。全項目が初期値ならsettings.tomlは存在しない。
- 開発版のupdates.tomlは移行後に.bakとして保全する。theme・auto_check_updatesなどの新設定を含むファイルはv0.2.2で読めないため、切り戻し時はバックアップを使う。
- 設定破損時は正常なバックアップからの復元を確認し、破損ファイルも保全する。正常なバックアップがなければ自動初期化しない。
- `--data-dir`で保存先を変更できる。

## 更新の内部仕様

- GitHub Releasesから取得し、サイズ・SHA-256・Assetの情報を検証する。
- 別プロセスで本体終了を確認してInno Setupを実行し、登録とEXEのバージョンを確認してバックグラウンド再起動する。
- 完全なロールバック、署名付きマニフェスト、コード署名は未対応。
- ローカル結合試験の手順・範囲は`local-update-testing.md`、v0.3.0の実機検証記録は`v0.3.0-validation.md`を参照する。

## 公開範囲

Starlightへ渡す原稿は`docs/user-guide.md`だけとし、この文書や検証記録・スクリーンショット管理用READMEは公開ページに含めない。公開する内容はリリース前に対象バージョンと照合する。
