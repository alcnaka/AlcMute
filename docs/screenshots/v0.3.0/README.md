## 撮影条件・注意

- 接続済み・ミュート中の画像は実際のVRChatの状態を取得。切り替え撮影後はマイク有効へ戻した。
- 01・02はVRChat未起動時、04・05は接続確認前の状態。接続済みの代表画像には08を使用する。
- 05の未保存表示はテーマ選択のプレビューによるもの。設定変更は保存せず破棄した。
- ショートカットの表示は撮影環境の設定（Left Ctrl + Right Ctrl）。製品の既定値を説明する場合は、既定がCtrl + Alt + Mであることを本文に明記する。
- セットアップは既存インストールがある環境で撮影。インストールの実行はせず、キャンセルしてAlcMuteを起動し直した。
- セットアップ画面や終了確認は、アプリのカスタムテーマとは異なるWindows標準の外観。

## 追加撮影が必要な素材

| 素材 | 主な用途 | 未撮影の理由・条件 |
| --- | --- | --- |
| トレイの右クリックメニュー、状態別トレイアイコン | README・Booth・常駐操作のマニュアル | 現在の撮影ツールではタスクバーを操作対象として取得できなかった。手動撮影が必要 |
| 新規インストール時の保存先選択 | 導入マニュアル | 既存インストール環境では画面が省略される。新規のテストユーザー／VMで撮影 |
| Portable版の自動起動の無効表示 | 配布形式の違い・マニュアル | 今回はInstaller版を撮影。Portable版を別途起動して撮影 |
| VRChat側のOSCとToggle Voiceの設定画面 | 初回設定マニュアル | VRChat側の操作・個人情報の映り込みを確認したうえで別途撮影 |
| 新版検出・ダウンロード・更新完了 | 更新マニュアル | 実際に後続の正式版が存在する環境で撮影。架空の更新通知は作成しない |
