VRChatが非アクティブでも、ショートカットやWindowsの通知領域からマイクのミュートを
切り替える、Rust製のWindows常駐アプリです。VRChat公式OSCを使用します。

## 機能

- グローバルショートカットによるミュート切り替え
- 左右のCtrl・Altなどを区別した登録、修飾キーだけの組み合わせ、`K + L`などの同時押し
- VRChatから取得したミュート状態に応じたトレイアイコン
- トレイメニューと、動作を選べるダブルクリック
- トレイメニューまたは設定画面の「AlcMuteについて」で制作者・リポジトリ・ライセンス本文を表示
- 設定画面、項目ごとのReset、確認付きの全初期化
- Windowsサインイン時の自動起動（Installer版）、手動起動時の設定画面表示の切り替え
- GitHub Releasesによる更新確認、Installer版のアプリ内更新
- 表示倍率が異なるモニター間でのウィンドウ移動に対応

対応OSはWindows 10 / 11です。

Windows実行ファイルの会社名は`Alcnaka`、製品名は`AlcMute`です。
ファイルのバージョン情報からも確認できます。

## 使い方

1. VRChatでOSCと「Toggle Voice」を有効にします。
2. `alcmute.exe`を起動します。初期状態では設定画面を表示します。
3. ショートカットを変更する場合は「キーを変更」を押し、組み合わせを押してから
   すべて離します。「保存」で反映します。記録中のみミュートのショートカットを停止します。
4. 「閉じる」やウィンドウの×は設定画面だけを閉じます。アプリの終了は
   トレイメニューの「終了」、または設定画面の「ツールを終了」から行います。

起動済みの状態でEXEやスタートメニューからもう一度起動すると、既存の設定画面を開き、
起動済みのAlcMuteを表示したことを設定画面内の通知で案内します（OKで閉じます）。
Windowsサインイン時などのバックグラウンド起動では案内を表示しません。

| 設定 | 初期値 |
| --- | --- |
| ショートカット | Ctrl + Alt + M |
| トレイのダブルクリック | ミュート切り替え |
| Windowsサインイン時の起動 | 無効（Installer版のみ設定可能） |
| 起動時に設定画面を表示 | 有効 |
| OSC送信先 | 127.0.0.1:9000 |
| OSC受信先 | 127.0.0.1:9001 |

キー入力は他のアプリにも渡されます。設定変更がある場合だけ「保存」が有効になります。
全初期化は保存済み設定を削除し、Installer版では管理対象の自動起動も無効にします。
Portable版は、旧版が作成したものも含め、Windowsの自動起動登録を変更しません。

設定の変更に失敗した場合は画面で案内します。必要に応じて設定を再保存するか、
AlcMuteを再起動してください。

同じユーザー・Windowsセッションで手動起動を繰り返すと、既存の設定画面を前面に表示します。
Windowsサインイン時とアップデート後は画面を開かず常駐します。起動に失敗した場合は、
エラー概要と`error.log`の保存先をダイアログに表示します。ログは設定と同じフォルダーです。
設定ファイルが破損し、正常な`settings.toml.bak`がある場合は、復元するか確認します。
復元前の破損ファイルは別名で保全します。正常なバックアップがなければ自動初期化せず停止します。

ミュート状態を取得できない場合も、トレイ・設定画面・ショートカットから切り替えを操作できます。

ショートカットが他のアプリと競合した場合は、そのショートカットを無効にして起動し、設定画面に警告を表示します。別のキーに変更して「保存」してください。トレイからのミュート操作は引き続き利用できます。
状態が不明なときはミュート済みとは表示しません。VRChat未起動時も操作できますが、
実際に反映するにはVRChat側のOSCと「Toggle Voice」が必要です。
短時間に操作が集中した場合は、少し待ってから操作するよう状態欄に表示します。

## 設定ファイル

既定の保存先は次のとおりです。

```text
%LOCALAPPDATA%\Alcnaka\AlcMute\settings.toml
```

旧保存先`%LOCALAPPDATA%\VRChatMuteController`の設定は、初回起動時に引き継ぎます。
新保存先に設定がある場合はそちらを優先し、旧ファイルはバックアップとして残します。
自動起動の移行はInstaller版のインストール時に行います。旧版を終了してからインストールしてください。
安全に識別できない登録は削除せずログに記録します。Windowsのスタートアップ設定で無効化した状態は維持します。
別の保存先を使う場合は`alcmute.exe --data-dir <フォルダー>`を指定します。
初期値の項目は保存を省略するため、全項目が初期値なら設定ファイルは存在しません。
自動起動の状態はWindows登録から読み取り、`settings.toml`へは保存しません。
更新確認の設定は別の`updates.toml`に保存するため、既存の`settings.toml`はv0.2.2でも読み込めます。

## 配布

[GitHub Releases](https://github.com/alcnaka/AlcMute/releases)から取得します。v0.3.0は現在実装・検証中です。

| 形式 | ファイル名（v0.3.0） | 自動起動 | 更新 |
| --- | --- | --- | --- |
| Installer版 | `AlcMute-0.3.0-Setup.exe` | 設定可能 | 許可後にアプリ内から更新 |
| Portable版 | `AlcMute-0.3.0-Portable.zip` | 使用不可 | 通知とReleaseページ案内のみ |

Installer版は通常、管理者権限なしで`%LOCALAPPDATA%\Programs\Alcnaka\AlcMute`へインストールします。
更新時もインストール先と設定を維持します。インストール先はLocalAppData配下の専用フォルダーへ変更できます。
Program Filesなど管理者権限が必要な場所と、設定保存フォルダーへのインストールは許可しません。
旧Portable版などが入った未管理フォルダーの上書きも行いません。
アンインストール時は本体と自身を指す自動起動登録を削除し、ユーザー設定を保持します。

Portable版はZIPを展開して`alcmute.exe`を起動します。「Windowsサインイン時に起動」は操作できません。
旧Portable版の自動起動登録は起動しただけでは解除されません。整理する場合はInstaller版へ移行してください。

更新確認は起動時に一度行い、設定で停止できます。手動の「アップデートを確認」も使用できます。
新しい版があると設定画面とトレイメニューに表示します。通信エラー時もミュート機能は継続します。
Installer版はサイズ・SHA-256検証後、確認を得てアプリを終了し、Setupで更新・再起動します。
失敗時はログと案内を表示します。署名付き更新マニフェストとコード署名は今後の対応です。

変更内容は[変更履歴（CHANGELOG.md）](CHANGELOG.md)を参照してください。
