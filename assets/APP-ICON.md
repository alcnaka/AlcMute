# アプリアイコン

提供された4種類の画像を`img/alcmute-*.png`に保存しています。
青いマイクを製品ロゴ、緑をミュート解除、赤をミュート、灰色を未接続・状態不明として使用します。
提供された元画像をそのまま保存し、生成スクリプトで背景透過と余白除去を行います。
白い縁取りとハイライトを残す範囲は共通のマイク形状マスクで固定しています。
生成時にはアルファ領域で外周を詰め、縦横比を維持して正方形へ収めます。

`scripts/generate-app-icon.ps1`で元画像から以下を再生成できます。

- `app.png`: 設定・Aboutウィンドウ用（256px）
- `app.ico`: EXE・Setup・ショートカット用（16/24/32/48/256px）
- `mic-muted.png` / `mic-unmuted.png` / `mic-unknown.png`: 状態別トレイ用（64px）

旧SVGは参照されていません。アイコンの差し替えは元画像の更新とスクリプト実行で行えます。

画像生成による再描画は使用しません。RGB各成分235以上の白に近い画素のうち、
共通のマイク本体・ホルダー・ミュート斜線の保護マスク外を透明化します。
色付き画素は元画像の値を維持し、縮小時のみ補間します。
